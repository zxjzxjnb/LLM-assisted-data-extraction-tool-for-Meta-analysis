# MetaExtract 核对台 · 试用说明（30 秒上手）

一个**本地小工具**：帮你把土壤 / 土地利用变化荟萃分析里散落在 PDF 表格、图、正文里的
「处理 vs 对照」数值，**快速、可溯源地**核对出来。核心理念——**AI 只负责筛选和定位
（指给你看数字在哪），你来确认数值**；AI 默认不替你抄数字（一个静默的转录错误会直接污染效应量）。

如果你收到的是附带 **12 篇样例论文及缓存的独立 demo 包**，准备好依赖后即可离线试用，无需 API key。
GitHub 源码仓库不包含论文和缓存；从源码安装时，请先按 `使用说明.md` 准备自己的 PDF 和定位缓存。

---

## 一、打开它

- **Mac**：双击 `start_here_mac.command`
- **Windows**：双击 `start_here_windows.bat`

第一次会自动装好运行环境（需联网，约 1–3 分钟，**仅此一次**），之后秒开。
浏览器会自动打开核对台；**关掉那个黑色命令行窗口就等于关闭程序。**

> 打不开？
> - **Mac**：若提示「未受信任 / 来自身份不明的开发者」，右键点该文件 →「打开」→ 再「打开」。
>   若双击变成用文本编辑器打开，则：打开「终端」，输入 `bash ` （后带一个空格），把
>   `start_here_mac.command` 拖进终端窗口，回车。
> - **Windows**：若 SmartScreen 拦截，点「更多信息」→「仍要运行」。

## 二、试一下（这就是它的价值所在）

1. 左侧栏「Paper」默认选中 **P1**（样例里最完整的一篇，18 个定位区域）。
2. 中间「Located regions」是 AI 定位到的每个变量区域——**点一个**（比如第一个）。
3. 右侧填一个数值：在某个均值 / SD 框里随便填一个你在左侧 PDF 里看到的数字。
4. **看左侧 PDF**：你填的数字会被**红框点亮在原文出处**，蓝框是定位到的整块。
   —— 这就是核心：**证据贴着数字、一点就到**，核对时不用在 PDF 里大海捞针。
5. 底部能把核对好的记录组装成表、**导出 CSV**。

也可以左侧切换到 **P3 / P4** 看看：它们会显示「已被判为离题」并给出理由——这是
AI 筛选（Tier 1）在正常工作，不是出错。

## 三、几点说明

- **看样例完全离线**，不需要 API key。右侧那个「🤖 AI extract (Tier 3)」按钮才需要 key，
  试用阶段可以忽略（不点它即可，点了也只是提示不可用，不会出错）。
- 这是**研究原型**，目标是验证「AI 定位 + 人工确认」比纯手工更快更可靠，**不是完整荟萃平台**
  （效应量 / 森林图仍请用 metafor 等）。连续型（mean/sd/n）在 P1–P12 上做过本地烟雾测试，
  不代表跨论文的数值准确率已经验证。
- 用着哪里别扭、哪里看不懂、哪一步比 Excel 还慢——**都欢迎记下来告诉我**，这正是这轮想收集的。

谢谢试用！
